## Week 1 - History
- First writing system: cuneiform
- Babylonian number system was base-60
- Typewriter invented in 1967

## Week 2 - Bits and Bytes
- A byte is 8 bits!
- Unsigned: 0 to 255 in 8 bits
- Signed: -128 to 127 in 8 bits
- ASCII maps numbers to characters

## Week 3 - Text Structure
- Markdown is simple formatting for text, HTML is more complex
- Use \ to escape formatting in markdown!
- Unicode is similar to ASCII but with far, far more characters and numbers

## Week 4 - Keyboards and Editors
- Efficient typing reduces cognitive load... good thing I'm a proficient typist!
- Configure github pages with "_config.yml"

## Week 5 - Command Line Interfaces
- CLIs evolved from old computer terminals without monitors that printed responses onto paper
- Some functions are only available via CLI
- CLI's allow for automation using scripting.
